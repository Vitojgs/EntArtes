🗂️ Estrutura da Coleção

🟢 AUTH - Login (sem autenticação)
  • POST /api/auth/login
  • POST /api/auth/register
  • POST /api/auth/forgot-password
📋 BPMN 1 - Pedido de Aula (7 passos)
  • 1. Login como ENCARREGADO
  • 2. Obter disponibilidades (público)
  • 3. Criar pedido de aula (ENCARREGADO)
  • 4. Logout ENCARREGADO
  • 5. Login como DIRECAO
  • 6. Ver pedidos pendentes (DIRECAO)
  • 7. Aprovar pedido (DIRECAO)
📋 BPMN 2 - Remarcação de Aula (8 passos)
  • 1. Criar pedido PENDENTE (setup)
  • 2. Sugerir nova data (DIRECAO)
  • 3. Logout DIRECAO
  • 4. Login PROFESSOR
  • 5. Responder como PROFESSOR (Aceitar)
  • 6. Logout PROFESSOR
  • 7. Login ENCARREGADO
  • 8. Responder como ENCARREGADO (Aceitar)
📋 BPMN 3 - Aluguer de Figurino (5 passos)
  • 1. Obter anúncios ativos
  • 2. Criar reserva (ENCARREGADO)
  • 3. Logout ENCARREGADO
  • 4. Login DIRECAO
  • 5. Aprovar reserva (DIRECAO)
📋 BPMN 4 - Criar Anúncio (6 passos)
  • 1. Login ENCARREGADO
  • 2. Obter figurinos (lookup)
  • 3. Criar anúncio
  • 4. Logout ENCARREGADO
  • 5. Login DIRECAO
  • 6. Aprovar anúncio (PUT)

📋 BPMN 1 — Pedido de Aula

BPMN 1 Fluxo completo de marcação de aula
# Request Endpoint Notas
1 Login ENCARREGADO POST /api/auth/login Guarda token
2 Get disponibilidades GET /api/public/disponibilidades Sem auth, guarda slotId
3 Criar pedido POST /api/encarregado/aulas Guarda pedidoId
4 Logout POST /api/auth/logout Limpa token
5 Login DIRECAO POST /api/auth/login Guarda token
6 Pending GET /api/direcao/aulas/pending Guarda pendingPedidoId
7 Approve POST /api/direcao/aulas/:id/approve Estado → CONFIRMADA

Body do passo 3 (criar pedido):

{
  "data": "{{slotData}}",
  "horainicio": "{{slotHoraInicio}}",
  "duracaoaula": 60,
  "disponibilidade_mensal_id": {{slotId}},
  "salaidsala": 1,
  "privacidade": false
}

📋 BPMN 2 — Remarcação de Aula

BPMN 2 Fluxo completo de remarcação
# Request Endpoint Body
1 Criar PENDENTE POST /api/encarregado/aulas dados do pedido
2 Sugerir data PUT /api/aulas/:id/sugerir-nova-data novaData, motivo
3 Logout POST /api/auth/logout -
4 Login PROFESSOR POST /api/auth/login email, password
5 Responder PROF POST /api/aulas/:id/responder-professor acao: "aceitar"
6 Logout POST /api/auth/logout -
7 Login ENCARREGADO POST /api/auth/login email, password
8 Responder EE POST /api/aulas/:id/responder-encarregado acao: "aceitar"

📋 BPMN 3 — Aluguer de Figurino

BPMN 3 Fluxo completo de aluguer
# Request Endpoint Body
1 Get anuncios GET /api/anuncios -
2 Criar reserva POST /api/aluguer anuncioId, datas
3 Logout POST /api/auth/logout -
4 Login DIRECAO POST /api/auth/login email, password
5 Aprovar PUT /api/aluguer/:id/status status: "APROVADO"

📋 BPMN 4 — Criar Anúncio

BPMN 4 Fluxo completo de criação
# Request Endpoint Body
1 Login ENCARREGADO POST /api/auth/login email, password
2 Get figurinos GET /api/figurinos -
3 Criar anúncio POST /api/anuncios figurinoId, valor, datas
4 Logout POST /api/auth/logout -
5 Login DIRECAO POST /api/auth/login email, password
6 Approve PUT /api/anuncios/:id/approve -

▶️ Como Executar

Executar Fluxo Completo

  1. Expandir pasta 📋 BPMN 1 - Pedido de Aula
  2. Clicar com botão direito no primeiro request
  3. Selecionar Run Collection
  4. Executar em ordem sequencial

Executar Todos os Fluxos

  1. Clicar com botão direito na raiz da coleção
  2. Selecionar Run Ent'Artes BPMN Tests
  3. Configurar: Iterations: 1, Delay: 500ms

🔧 Executar via Newman (CLI)

# Instalação
npm install -g newman

# Executar coleção completa
newman run Entartes_BPMN_Tests.postman_collection.json \
  -e entartes_environment.postman_environment.json

# Com relatório HTML
newman run Entartes_BPMN_Tests.postman_collection.json \
  -e entartes_environment.postman_environment.json \
  --reporters cli,html \
  --reporter-html-export report.html

# Apenas BPMN 1
newman run Entartes_BPMN_Tests.postman_collection.json \
  -e entartes_environment.postman_environment.json \
  --folder "BPMN 1 - Pedido de Aula"

Variável Descrição

userId ID do utilizador (auto)

slotId ID da disponibilidade (auto)
pedidoId ID do pedido criado

⚠️ Troubleshooting

"Variable not defined"
Executar Login primeiro para guardar o token
401 Unauthorized
Requisitar novo token (expira em 1 hora)
403 Acesso Negado
Verificar role do utilizador logado
Dados não encontrados
Executar seed primeiro: cd backend && npm run seed

🌐 Endpoints Públicos (sem auth)

Endpoint Método Descrição
/api/auth/login POST Login
/api/auth/register POST Registar
/api/public/disponibilidades GET Todas as disponibilidades
/api/public/eventos GET Eventos publicados
/api/public/modalidades GET Modalidades
/api/contacto POST Formulário de contacto

📝 Notas

  • Todos os endpoints /api/* (exceto públicos) requerem JWT
  • O header Authorization: Bearer {{authToken}} é adicionado automaticamente
  • O header Content-Type: application/json é adicionado automaticamente
  • Alguns IDs são strings (não inteiros) nas respostas
  • O token expira em 1 hora
  • Os testes guardam automaticamente IDs para usar em requests subsequentes
💡 Dica: Os scripts de teste incluídos guardam automaticamente o token e IDs em variáveis, permitindo chains de requests sequenciais.
